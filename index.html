Assumptions & formulas

  • All category emissions computed in kg CO₂e, then converted to tons (÷ 1000).
  • Baseline uses EV_share=0%, KM_Reduction=0%, Plane LoadFactor = current slider value at time of baseline calculation.
  • Empty fields treated as zero. Negative values prevented. LoadFactor capped 0–100.
  • Displayed tons rounded to 1 decimal place.
  • Projection applies uniform annual % change to activity inputs for 5 years; sliders apply in optimized scenario.
Cars: cars_kg = Cars_km × 0.18 × (1 − 0.7 * EV_share/100) × (1 − KM_Reduction/100) Cars_tons = cars_kg / 1000 Trucks: Trucks_tons = (Trucks_km × 0.90) / 1000 Buses: Buses_tons = (Buses_km × 1.10) / 1000 Forklifts: Forklifts_tons = (Forklifts_hr × 4.0) / 1000 Cargo Planes: Planes_tons = (Planes_hr × 9000 × LoadFactor/100) / 1000 Office Lighting: Lighting_tons = (Lighting_kWh × 0.42) / 1000 Heating: Heating_tons = (Heating_kWhth × 0.20) / 1000 Cooling (A/C): Cooling_tons = (Cooling_kWh × 0.42) / 1000 Computing (IT): Computing_tons = (Computing_kWh × 0.42) / 1000 Subcontractors: Subs_tons = Sub1 + Sub2 + Sub3 Totals: Baseline_total_tons = sum(all category tons using baseline sliders default or EV=0, KMRed=0, LoadFactor=baseline) Optimized_total_tons = sum(all category tons using chosen optimization sliders) Percent_reduction = (Baseline_total_tons − Optimized_total_tons) / Baseline_total_tons × 100
